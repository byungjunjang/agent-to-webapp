## 2. 게이트

```
node $SKILL_DIR/scripts/check_lite.mjs 3
```

네 절이 차 있는지, 입출력 스키마에 json 블록이 있는지, 판정에 맞는 절(`## 규칙` 또는 `## 프롬프트` 와
`- 모델:`·`- 최대 토큰:`·`- 타임아웃:`)이 있는지, 출력 스키마가 모든 샘플의 공통 키를 덮는지 본다.

검사가 통과하면 학습자에게 `skill-spec.md` 를 보여주고 동의를 받는다. 동의하면:

```
node $SKILL_DIR/scripts/check_lite.mjs 3 --approve
```

판정을 다시 해야겠으면 `node $SKILL_DIR/scripts/check_lite.mjs rollback 2`.
