# 4단계 재검증 (skill)

언제 읽나: phase-3 통과, phase-4 미통과.

## 1. 학습자 안내

`skill-spec.md` 에 고정한 것 **그대로** 샘플 N건을 다시 돌린다.

- 「Claude 호출 유지」면 스펙의 프롬프트 원문을 그대로 쓴다. 말을 바꾸지 않는다
- 「코드로 고정」이면 스펙의 규칙만으로 뽑는다. 모르는 값을 판단으로 메우지 않는다
- 잘 안 되면 스킬을 즉흥으로 고치지 말고 멈춘다. 고쳐야 하면 `rollback 3` 으로 스펙부터 고친다

즉흥으로 메우면 검증이 아니라 시연이 된다. 웹 앱에는 메워 줄 사람이 없다.

## 3. 게이트

```
node $SKILL_DIR/scripts/check_lite.mjs 4
```

게이트가 직접 하는 일:

- `verify/sample-k.json` N건이 있고 JSON 으로 읽히는가 — 아니면 **실패**
- 각 결과가 스펙의 출력 스키마 키를 채우는가 — 빠지면 **실패**(빠진 키와 샘플 번호를 알려준다)
- 1단계 결과와의 키 차이는 참고로 알려만 준다

값 차이는 게이트가 판단하지 않는다. 코드는 스키마를 볼 수 있고 값의 옳고 그름은 볼 수 없다.

## 4. 차이를 허용할지

학습자가 정한다. `## 샘플별 차이` 를 보여주고 이대로 웹 앱에 넣어도 되는지 묻는다.

- 허용하면 그대로 5단계로
- 허용 못 하면 `node $SKILL_DIR/scripts/check_lite.mjs rollback 3` 뒤 스펙(프롬프트·규칙·스키마)을 고치고
  다시 돌린다
