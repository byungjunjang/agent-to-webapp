# 1단계 관찰 (dashboard)

언제 읽나: init 완료, phase-1 미통과.

## 1. 학습자 안내

대상 폴더에서 에이전트를 **1회** 돌리고 출력 산출물을 그대로 둔다. 경로는 STATUS 의 `output` 이다.

- 구글 시트가 원장이면 시트를 CSV 로 내보내 그 파일 경로를 준다. 이 스킬은 시트 API 나 외부 CLI 를 쓰지 않는다
- 산출물이 여러 파일이면 대시보드가 읽을 **한 벌**만 고른다. 나머지는 지금 범위 밖이다
- 에이전트를 고치지 않는다. 지금은 있는 그대로를 본다

돌리고 돌아오면 아래 프롬프트로 스키마를 적는다.

## 2. 산출물

`$LITE/runs/run-1.schema.md` 하나. 4단계가 같은 형식의 `run-2.schema.md` 와 대조하므로 절 이름을 바꾸지 않는다.

### 프롬프트 1 — 출력 스키마 적기

```
<출력 산출물 경로> 를 읽고 docs/agent-to-webapp-lite/runs/run-1.schema.md 를 아래 일곱 절로 적어줘.
절 이름과 순서를 바꾸지 말 것. 없는 항목은 '없음' 또는 '- 없음' 이라고 적는다.

## 출처
파일 이름과 경로. 시트면 시트 이름도.

## 열
표 하나로 적는다. 머리글은 이 줄 그대로:
| 열 | 타입 | 예시값 | 빈 값 비율 |
타입은 문자열·정수·실수·날짜·불리언 중에서 고른다. 예시값은 실제 값 하나를 그대로. 빈 값 비율은 % 로.

## 행 수
숫자.

## 유일 키 후보
행 하나를 유일하게 가리키는 열 또는 열 조합(예: channel + sold_on). 찾지 못하면 '없음'.

## 갱신 시각 열
언제 채워졌는지 알려주는 열 이름. 없으면 '없음'.

## LLM 문장 열
에이전트가 문장으로 쓴 열(점검 결과, 확인할 것 같은 자유 서술). 목록으로. 없으면 '- 없음'.

## 민감 열 후보
계좌·급여·상담 원문·개인 이름처럼 대시보드에 싣기 곤란한 열. 목록으로. 없으면 '- 없음'.

파일을 직접 읽어서 적을 것. 추측하지 말고, 모르면 그 칸에 '확인 필요' 라고 적는다.
```
