# 관찰 입력 3종

학습자가 지정한 입력을 같은 폴더 이름으로 복사했다. 세 폴더의 도면은 모두 대상 프로젝트 원본
`part_drawing_EV_input_shaft.pdf`(ND-IS-042 Rev.A, SCM420H, ECD 0.45–0.65 mm, 0.82 kg)와 같은 파일이다.

| 종류 | 입력 | 왜 이것인가 |
|---|---|---|
| 쉬움 | `1-easy-novadrive/`: 원본 샘플. `customer_rfq_email.pdf` + 도면 PDF. 대상의 `input/NovaDrive/` 와 같은 파일 | 기준선. CLAUDE.md 의 7단계와 스킬 4개가 이 입력을 두고 쓰였다(고객사 약칭 예시도 `NovaDrive`). 설계대로 흘러갈 때의 단계 순서와 스크립트 호출을 여기서 잡고 2·3번을 이것과 비교한다 |
| 보통 | `2-normal-helios/`: 합성 RFQ. `customer_rfq_email.md`(Helios, P/N HX-2210) + 원본 도면 | 순서가 유지되는지. 필요한 정보는 대부분 있지만 형식과 값이 원본과 다르다. 이메일이 PDF 가 아니라 텍스트이고, 수량은 로트가 아니라 월 5,000개 × 12개월, 납기는 "PO 후 6주" 다. ECD 상한이 1.2 mm 라 이메일 값대로면 규칙 §2 에서 진공침탄이 빠진다. 7단계가 그대로 돌아야 하는 입력이므로 순서가 흔들리면 필드 차이가 원인이다 |
| 예외 | `3-edge-orion/`: 합성 RFQ. 두 줄짜리 `customer_rfq_email.md`(Orion) + 원본 도면 | 모델이 무엇을 알아서 처리하는지 드러낸다. 재질은 "steel, 확인 예정" 이고 수량·경도·납기는 없이 "도면대로 견적" 만 있다. 도면이 재질·경도는 메워 주지만 `lot_size`·`delivery_days` 는 어디에도 없는데 `validate_specs.py` 는 둘 다 양수를 요구한다. CLAUDE.md 에러 처리 표에는 고객이 정보를 안 준 경우가 없다. 가정값을 넣는지, 멈추고 묻는지, 계산·견적서 단계를 건너뛰는지가 여기서 갈린다 |

## run 기록에서 먼저 찾을 곳

- 1 NovaDrive: 7단계를 CLAUDE.md 순서대로 밟았는지. 스크립트 없이 JSON 을 고쳐 다시 저장하는 2단계(누락 스펙)와 5단계(리드타임)를 어떻게 했는지
- 2 Helios
  - 이메일과 도면이 어긋난다. P/N(HX-2210 / ND-IS-042), ECD(0.8–1.2 / 0.45–0.65), 심부경도(30–45 / 30–42), 흔들림(≤0.05 교정 요구 / ≤0.03 연삭 수정 불가). 어느 쪽을 믿느냐에 따라 루트 판정이 달라진다
  - `lot_size` 를 무엇으로 잡았는지(월 5,000 / 연 60,000 / 기타). 배치 수와 단가가 여기에 달렸다
  - 회사명·담당자·RFQ 번호가 없다. `customer_company`, 견적서 파일명 `견적서_[RFQ번호].xlsx`, 이메일 호칭을 어떻게 채웠는지
  - 교정·포장·PPAP 가 명시돼 §3 누락 체크리스트 6개 중 3개가 채워진다. `missing_specs` 가 그만큼 줄었는지
- 3 Orion
  - 재질을 이메일의 "steel" 과 도면의 SCM420H 중 무엇으로 썼는지
  - `lot_size`·`delivery_days` 를 지어냈는지, 비워서 검증을 실패시켰는지, 거기서 멈췄는지
  - 회신 이메일이 견적 안내에서 정보 요청으로 바뀌었는지. §3 체크리스트 밖의 누락(재질 확정·수량·경도·납기)을 어디에 적었는지

## 학습자 변경 (2026-09-11, 관찰 실행 전)

스킬의 경고대로 `2-normal-helios/customer_rfq_email.md` 를 도면 ND-IS-042 Rev.A 와 맞게 고쳤다. 처음 초안은
ECD·경도·흔들림이 도면과 달라 "보통" 이 두 번째 예외가 됐다. 위 표와 "먼저 찾을 곳" 의 Helios 불일치 항목은
더 이상 해당하지 않는다. 남은 차이는 텍스트 이메일, 고객 P/N 과 도면 번호가 따로 있음, 첫 로트 2,500 + 월 5,000,
납기 "PO 후 6주", 교정·포장·PPAP 명시다.
