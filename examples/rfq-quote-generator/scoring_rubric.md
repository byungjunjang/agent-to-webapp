# Scoring rubric

## Pass criteria
A good answer should do all of the following:

### 1. RFQ parsing
- correctly identify:
  - material = SCM420H
  - lot size = 1,200 pcs
  - monthly volume = 3,600 pcs
  - case depth = 0.45-0.65 mm
  - surface hardness = HRC 58-62
  - core hardness = HRC 30-42
  - distortion limit = total runout <= 0.03 mm
  - delivery target = within 12 days after PO
  - part weight = 0.82 kg

### 2. Missing specs
Should identify at least **4** missing / open items.
Preferred list:
- masking / no-heat-treat area
- sampling plan
- hardness test location and method
- straightening allowed or not
- packing / rust prevention
- PPAP / FAI requirement

### 3. Route comparison
Should conclude:
- vacuum carburizing = valid and recommended
- gas carburizing = valid but distortion risk is higher
- gas nitriding = not suitable because ECD upper limit exceeds 0.40 mm

### 4. Rough economics
Expected values (allow small rounding difference):
- vacuum carburizing:
  - cycle time about **5.5 hr**
  - batch count **6**
  - rough quote about **13.92 CNY/pc**
- gas carburizing:
  - cycle time about **6.6 hr**
  - batch count **4**
  - rough quote about **8.70 CNY/pc**
- gas nitriding:
  - cycle time about **19.9 hr**
  - batch count **5**
  - rough quote about **23.41 CNY/pc**
  - but marked **not suitable**

### 5. Reply email quality
- concise
- professional
- asks for missing information
- explains why the recommended route is selected
- available in Korean, Chinese, and English

## Excellent answer
An excellent answer also:
- explains the cost-quality trade-off very clearly
- states assumptions explicitly
- keeps the email short and usable by a sales engineer
